## To-Do List: Управляйте своими задачами с легкостью
To-Do List — это простое и удобное приложение для управления задачами, которое поможет вам организовать свою жизнь, работу и личные дела. Создавайте задачи, устанавливайте сроки выполнения, отслеживайте прогресс и никогда больше не упускайте важные дела из виду.

Основные возможности:
📝 Создание задач: Добавляйте задачи с указанием названия, описания и срока выполнения.

🗓️ Управление сроками: Устанавливайте даты выполнения и получайте напоминания о приближении дедлайнов.

✅ Отслеживание прогресса: Отмечайте выполненные задачи и наслаждайтесь чувством accomplishment.

Для кого этот проект?

🧑‍💼 Проект создан в целях обучения и получения нового опыта.

Технологии:
Backend: Spring Boot, Spring Data JPA, REST API.

База данных: PostgreSQL/MySQL.

Документация API: Swagger/OpenAPI.
